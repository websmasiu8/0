Términos y Condiciones

Última actualización: 14 de noviembre de 2026.

Al ingresar y utilizar Sabor Digital, el usuario acepta estas condiciones. Si no está de acuerdo, debe abstenerse de utilizar el sitio.

1. Uso del sitio

Sabor Digital permite consultar un menú, personalizar productos, enviar pedidos y solicitar la cuenta de una mesa. El usuario se compromete a proporcionar información correcta, revisar su pedido antes de enviarlo y utilizar el servicio de manera lícita y respetuosa.

2. Pedidos, precios y disponibilidad

Los pedidos están sujetos a confirmación, disponibilidad de productos y validación por parte del establecimiento. Los precios, descripciones e imágenes pueden actualizarse. Si existe un error o un producto no está disponible, el establecimiento podrá contactar al cliente para aclararlo antes de preparar el pedido.

3. Pagos

La selección de un método de pago al solicitar la cuenta sirve para informar al personal. Esta versión del sitio es una herramienta de gestión de pedidos y no procesa ni confirma pagos electrónicos. El pago se realiza y verifica directamente con el establecimiento.

5. Disponibilidad y responsabilidad

El servicio puede interrumpirse por mantenimiento, fallas de conexión o causas ajenas al establecimiento. El usuario debe verificar que el pedido haya sido enviado correctamente; la visualización de un mensaje o pantalla no sustituye la confirmación del personal.

Aviso de Privacidad

Responsable del tratamiento: MANUEL ALESSANDRO SERRATO MiLLARES. Contacto: Websmasiu@gmail.com.

Este aviso explica qué información puede tratarse cuando utilizas Sabor Digital.

1. Información tratada

Según las funciones utilizadas, el sistema puede registrar el número de mesa, productos solicitados, cantidades, personalizaciones, notas del pedido, hora, estado del pedido, solicitud de cuenta y método de pago elegido. No solicites ni escribas datos sensibles o información de tarjetas en las notas del pedido.

2. Finalidades

La información se utiliza para recibir y preparar pedidos, identificar la mesa, calcular y presentar el total, atender solicitudes de cuenta, coordinar la atención del personal, mantener el funcionamiento del servicio y resolver inconvenientes relacionados con el pedido.

3. Almacenamiento y terceros

La aplicación utiliza Supabase como servicio de base de datos y autenticación para gestionar la información operativa. Los datos necesarios pueden ser tratados por ese proveedor para prestar el servicio, de acuerdo con sus condiciones y medidas de seguridad. No incluyas información que no sea necesaria para realizar tu pedido.

4. Conservación y seguridad

La información se conservará durante el tiempo necesario para gestionar los pedidos, atender reclamaciones y cumplir obligaciones aplicables. Se adoptan medidas técnicas y organizativas razonables, pero ningún sistema puede garantizar seguridad absoluta.

5. Derechos y solicitudes

Puedes solicitar información sobre tus datos, su actualización o corrección, y presentar consultas o reclamaciones a través de Websmasiu@gmail.com. El responsable atenderá las solicitudes conforme a la normativa aplicable de protección de datos personales. Si el tratamiento está sujeto a la legislación colombiana, se tendrán en cuenta, entre otras, las reglas de la Ley 1581 de 2012.
